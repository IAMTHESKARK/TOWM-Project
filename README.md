# The Other Wes Moore - Multimodal Project

An interactive web-based educational project exploring the powerful narrative of "The Other Wes Moore" by Wes Moore. This multimodal project examines the parallel lives of two men with the same name who grew up in similar circumstances but ended up on vastly different paths.

## 📖 About the Book

"The Other Wes Moore" tells the story of two African-American men named Wes Moore who shared similar backgrounds but had dramatically different outcomes:
- **Wes Moore (Author)**: Rhodes Scholar, paratrooper, White House Fellow, and bestselling author
- **Wes Moore (The Other)**: Currently serving a life sentence for murder

## 🌟 Project Features

This multimodal project includes:

### 📄 HTML Pages
- **index.html** - Main landing page with hero section and interactive timeline
- **characters.html** - Detailed character profiles and family comparisons
- **themes.html** - Major themes, quotes, and discussion questions
- **analysis.html** - Literary analysis, comparative framework, and critical reception

### 🎨 CSS Styling
- **styles.css** - Comprehensive stylesheet with:
  - Responsive design for mobile and desktop
  - Interactive animations and hover effects
  - Professional typography and color scheme
  - Accessible design principles

### ⚡ JavaScript Functionality
- **script.js** - Interactive features including:
  - Modal dialogs for character information
  - Timeline event exploration
  - Smooth scrolling navigation
  - Dynamic content loading
  - Animation triggers

## 🚀 Getting Started
